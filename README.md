# Projeto-Testes

Coleção de projetos e testes de aplicações.

## Projetos

- **painel-gastos** — painel de controle de gastos pessoais em PHP 8.1+ com SQLite: despesas, categorias, orçamentos, relatórios com gráficos e importação de extratos em CSV. Ver [painel-gastos/README.md](painel-gastos/README.md).
- **organiza-plus** — gerenciador de tarefas com backend em C++ (`cpp-httplib` + `nlohmann/json`) e front-end em HTML/CSS/JS.
- **Pomodoro** — timer Pomodoro em HTML, CSS e JavaScript.
- **diários de aprendizagem** — página de diários de aprendizagem.
- **arquivo c++** — exercícios em C++.

> Binários compilados (`*.exe`) não são versionados.
